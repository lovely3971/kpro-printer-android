# KPRO Printer Android — BT-58L Test Bridge

First native Android test build for Kanakku Pulla PRO receipt printing.

## Test flow
1. Put PeriPeri BT-58L/BT-58TSC in **Receipt Mode**.
2. Android Settings → Bluetooth → pair the printer (PIN `0000` if asked).
3. Install the APK generated by GitHub Actions.
4. Open **KPRO Printer** → allow Nearby devices/Bluetooth permission.
5. Select the paired printer → **Connect Printer**.
6. Tap **Print 58mm Test Receipt**.

This build uses Bluetooth Classic RFCOMM/SPP UUID `00001101-0000-1000-8000-00805F9B34FB` and sends a small ESC/POS receipt.

## Build APK on GitHub
Push these files to the repository. Open **Actions → Build KPRO Printer APK → Run workflow** (or let the push trigger it). When green, open the workflow run → Artifacts → download **KPRO-Printer-Android-Debug-APK**.

## Scope of V1
This is deliberately a printer-transport test. It does not yet receive real bill data from the KPRO web app. Once BT-58L test printing is confirmed, the KPRO handoff/deep-link layer can be added without changing the existing billing UI.
